# Food-Item-Performance-Dashboard-
Python -based data visualization project.
Food Item Performance Dashboard 📊

Project Description

The Food Item Performance Dashboard is a Python-based data visualization project that analyzes food sales data and presents useful insights through different charts and summary statistics.

It helps understand the sales performance of different food items, track revenue trends, and identify popular food items.

Technologies Used

- Python
- Pandas
- Matplotlib
- Excel

Features

- Bar Chart: Displays the total quantity sold for each food item.
- Line Graph: Shows the seven-day average revenue trend.
- Pie Chart: Represents the percentage share of each food item in total quantity sold.
- Summary Statistics: Displays average, highest, and lowest quantities sold, total unique food items, and total quantity sold.

Project Output

The project generates a visual dashboard containing charts and summary statistics to make sales data easier to understand and analyze.

Learning Outcomes

- Understanding data analysis using Pandas.
- Creating charts using Matplotlib.
- Working with Excel files in Python.
- Presenting data through visualizations.
